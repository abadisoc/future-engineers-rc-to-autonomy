# Contributing and evidence standards

The student team owns engineering decisions and should review each change. Use descriptive commits such as `Document measured steering radius` or `Add front sensor timeout logs`. Do not backdate commits or claim untested performance. Keep raw measurements and a paired before/after record for significant revisions. When a hardware interface changes, update the wiring map, BOM, photos, and firmware pin map in the same revision.

Before a public submission, remove private contact details and ensure team photo consent. Refer to the official competition rules for publication and deadline requirements. This repo is a working engineering journal, not a copy of another team's source or documentation.
