# As-built hardware record

The [bill of materials](bom.csv) distinguishes **reported plan**, **candidate**, and **verified installed**. Change a row to `verified installed` only after the team records a label/photo and actual wiring. Add the final motor driver schematic, power distribution diagram, sensor mounting drawing, and any CAD or printable files here. Link source files, not only screenshots or externally hosted models.

Record fuse/switch location, measured battery and 5 V voltage under motor load, motor and servo currents, actual ground connections, and the steering interface. The USB breadboard sensor prototype is not a final power schematic. [Sensor pin assignments](../docs/03-power-and-sensing.md) should be checked against the assembled car.
