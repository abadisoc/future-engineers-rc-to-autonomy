# Raw data and trial results

`trials-template.csv` is an **empty schema**, not a results sheet. Copy it to a dated file after trials and add one row per attempt. Put raw serial logs in `raw/`, with the matching trial ID in the filename. Include failed attempts, the firmware commit, conditions, and a video reference. Do not fill historical runs from estimates.

For sensor calibration, save the observed distance readings, known target distance, target material/angle, mount height, and battery/USB supply configuration. For the final challenges, record direction, layout identifier, lap count, contact count, parking outcome, time, and failure reason. Summaries should show both successes and sample size.
